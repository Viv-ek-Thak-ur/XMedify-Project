# Medify

Medify is a responsive React application that allows users to search medical centers by state and city, view available hospitals, and book appointments. The application uses external APIs to fetch hospital data and stores bookings using Local Storage.

## Live Demo

https://x-medify-project-ten.vercel.app/

## GitHub Repository

https://github.com/yourusername/your-repository

## Features

- Search medical centers by state and city
- Display hospitals using API data
- Book appointments
- View booked appointments
- Store bookings using Local Storage
- Responsive design for desktop, tablet, and mobile devices

## Tech Stack

- React.js
- React Router DOM
- JavaScript (ES6+)
- CSS Modules
- Vite

## Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/your-repository.git
```

### Navigate to the project folder

```bash
cd your-repository
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```
